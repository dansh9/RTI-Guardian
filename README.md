
# RTI Guardian

מערכת ניטור אבטחה לבית חכם עם RTI controller.

## רקע
פרצו לנו לבית החכם. שמנו לב לתריסים שירדו
ואורות שהלכו לבד. מצאנו פורטים פתוחים על
ה-RTI controller. חסמנו אותם — אבל רציתי לדעת
אם זה מספיק ולקבל התראה אם משהו משתנה.

## מה המערכת עושה
- בודקת אילו פורטים פתוחים על ה-RTI controller
- סורקת את הרשת הביתית לאיתור מכשירים לא מוכרים
- שומרת baseline ומתריעה על שינויים

## סטטוס
